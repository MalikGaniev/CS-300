# CS 300 — Data Structures and Algorithms Portfolio

## Project Overview

This repository contains my portfolio artifacts from CS 300: Data Structures and Algorithms at Southern New Hampshire University. The projects demonstrate my understanding of data structures, algorithm efficiency, and software development using C++.

### 1. What was the problem you were solving in the projects for this course?

The goal of these projects was to develop a program that could organize and display course information for a Computer Science advising system. The program needed to read course data from a file, store the information using an appropriate data structure, and display a list of courses in alphanumeric order. I also needed to analyze the run-time and memory efficiency of different data structures to determine which approach would be most effective.

### 2. How did you approach the problem? Why are data structures important?

I approached the problem by comparing vectors, hash tables, and binary search trees. I considered how each structure stores, searches, and sorts information, along with its run-time and memory requirements. Understanding data structures is important because choosing the right structure can improve performance, reduce unnecessary processing, and make software more efficient.

### 3. How did you overcome roadblocks?

One challenge was understanding how different data structures affect program performance and how to organize course information correctly. I worked through these challenges by reviewing algorithm concepts, testing my code, debugging errors, and breaking the problem into smaller tasks. This helped me better understand how data structures and algorithms work together.

### 4. How has this project expanded your approach to designing software?

This project taught me to consider efficiency and organization before beginning implementation. Instead of focusing only on making a program work, I learned to evaluate how different solutions affect performance and scalability. I also gained experience planning algorithms, analyzing complexity, and choosing data structures based on project requirements.

### 5. How has this project evolved the way you write maintainable, readable, and adaptable programs?

I learned the importance of writing organized and understandable code. Using meaningful variable names, separating functionality into functions, adding useful comments, and testing individual components makes programs easier to maintain. I also learned that selecting appropriate data structures helps create programs that can be modified or expanded without unnecessary complexity.
